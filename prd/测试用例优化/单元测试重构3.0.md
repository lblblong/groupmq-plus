## 3. 技术约束与注意事项

1.  **路径修正**: 同样注意 `../../src` 和 `../helpers/redis` 的路径调整。
2.  **超时设置**:
    - `resilience` 目录下的测试通常涉及 `setTimeout` 等待、网络断连模拟或大数据处理。
    - 请检查每个 `it` 的超时时间设置（如 `30000` 或 `60000` ms），确保在 CI 环境下不会因为机器慢而 Flaky。
3.  **Redis 连接管理**:
    - 断连测试 (`redis-connection.test.ts`) 经常会主动调用 `redis.disconnect()`。务必确保 `afterAll` 钩子能正确清理连接，且不会影响其他测试文件（Vitest 默认并行运行文件，但同一个文件内是串行的；如果使用全局 Redis 实例需小心）。建议每个测试文件内部创建独立的 Redis 连接实例。
