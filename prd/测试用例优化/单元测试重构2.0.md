## 3. 技术约束与注意事项

1.  **Redis 命名空间隔离**:
    - 在合并后的文件中，确保每个 `describe` 或 `it` 块使用唯一的 `namespace`（如 `test:flow:api:${Date.now()}`），避免不同测试用例间的 Redis 数据污染。
2.  **Import 路径**:
    - 继续注意修正 `../../src` 和 `../helpers/redis` 的引用路径。
3.  **Flow 测试的特殊性**:
    - Flow 测试通常涉及较长的等待时间（等待子任务完成），请确保测试超时时间（Timeout）设置合理，或使用适当的 `waitFor` 逻辑。
