# PRD: 单元测试重构 - 第一阶段 (基础结构与核心模块)

## 1. 背景与目标

目前项目的测试文件（`*.test.ts`）全部平铺在根目录，导致文件数量过多（约 30 个），且存在逻辑重复（如自动批处理分散在两个文件中）。
**本阶段目标**：建立清晰的 `tests/` 目录结构，迁移辅助工具，并重构“核心功能”与“批处理功能”的测试用例，删除冗余文件。

## 2. 任务清单

### 任务 2.1: 建立目录结构

请在项目根目录下创建 `tests/` 文件夹，并建立以下子目录：

- `tests/core/` (存放 CRUD、幂等性、基础处理逻辑)
- `tests/features/` (存放批处理、流式任务等高级特性)
- `tests/helpers/` (存放测试辅助工具)

### 任务 2.2: 迁移辅助工具

1. 将根目录下的 `helpers/redis.ts` 移动到 `tests/helpers/redis.ts`。
2. **注意**：你需要扫描所有测试文件，将引用 `import { createRedis } from './helpers/redis'` 修改为新的相对路径（例如 `import { createRedis } from '../helpers/redis'`）。

### 任务 2.3: 核心模块 (Core) 重构

将以下现有文件移动、重命名或合并到 `tests/core/` 目录：

1. **合并 CRUD 测试**:

   - **源文件**: `queue.job.test.ts`, `queue.remove.test.ts`
   - **目标文件**: `tests/core/job-crud.test.ts`
   - **操作**: 将这两个文件中的测试用例合并。保留 `Job Tests` 的逻辑以及 `remove` 相关的测试。

2. **迁移基础处理与清理测试**:

   - **源文件**: `queue.clean.test.ts`
   - **目标文件**: `tests/core/maintenance.test.ts`
   - **操作**: 直接迁移并重命名，用于测试 `queue.clean()` 相关的逻辑。

3. **迁移幂等性测试**:
   - **源文件**: `queue.idempotence.test.ts`
   - **目标文件**: `tests/core/idempotence.test.ts`
   - **操作**: 直接迁移。

### 任务 2.4: 特性模块 (Features) - 批处理重构

将分散的自动批处理（Auto-Batching）测试合并：

1. **合并批处理测试**:
   - **源文件**: `queue.autobatch-simple.test.ts`, `queue.autobatch-ordering.test.ts`
   - **目标文件**: `tests/features/batching.test.ts`
   - **操作**:
     - 创建新文件 `tests/features/batching.test.ts`。
     - 将上述两个文件中的 `it` 测试用例全部迁移过去。
     - 确保 `describe` 块清晰，例如可以分为 `describe('Simple Batching')` 和 `describe('Batching with Ordering')`。
     - 去除重复的 `beforeAll/afterAll` Redis 连接代码，统一使用一套 setup/teardown。

### 任务 2.5: 清理冗余文件

1. **删除** `queue.basic.test.ts`。
   - **原因**: 该文件仅测试了 `queue.name`，此逻辑极其简单且在其他集成测试中已隐式覆盖，无需单独文件。

## 3. 技术约束与注意事项

1. **导入路径修正**:

   - 所有移动后的测试文件，其对源代码的引用 `import { Queue, Worker } from '../src'` 可能需要变成 `../../src`，请务必根据文件层级自动修正。
   - 对 `tests/helpers/redis` 的引用必须修正。

2. **保留原有逻辑**:

   - 除了去除重复的 `describe` 外层包裹或重复的 Redis 连接代码外，**不要修改测试内部的断言逻辑**。确保重构后的测试覆盖率不下降。

3. **验证**:
   - 重构完成后，请确保可以运行测试命令（如 `npx vitest` 或 `npm test`）并通过所有测试。
