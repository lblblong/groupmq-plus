## Job

Job entities are returned from `queue.add(...)`, `queue.getJob(id)`, and from worker events. They mirror BullMQ's `Job` shape and expose helpers that delegate to the `Queue`.

### Setup

```ts
import Redis from 'ioredis'
import { Queue } from 'groupmq'

const redis = new Redis()
const queue = new Queue<{ n: number }>({ redis, namespace: 'docs' })
const job = await queue.add({ groupId: 'g1', data: { n: 1 } })
```

### updateData(data) / update(data)

Replace the job payload in Redis.

```ts
await job.update({ n: 2 })
// or
await job.updateData({ n: 2 })
```

### promote()

Promote this job if delayed so it runs immediately.

```ts
await job.promote()
```

### remove()

Remove this job regardless of state (waiting, delayed, processing).

```ts
await job.remove()
```

### retry()

Retry this job using queue defaults and backoff.

```ts
await job.retry()
```

### waitUntilFinished(timeoutMs?)

Wait for this job to finish (completed or failed). Resolves with return value or rejects with failure reason. Optional timeout in ms (0 = no timeout).

```ts
const result = await job.waitUntilFinished(10_000)
```

### getState()

Get the current status inferred from Redis.

```ts
const state = await job.getState()
```

### getChildrenValues()

(Parent jobs only) Get all child job results and failures. Returns array of child return values, Errors for failed children, or null for unresolved results.

```ts
// In parent job handler
const worker = new Worker({
  queue,
  handler: async (job) => {
    if (!job.parentId) {
      // This is a parent job
      const childResults = await job.getChildrenValues()
      // childResults: Array<T | Error | null>
      
      const successCount = childResults.filter(r => !(r instanceof Error)).length
      const failureCount = childResults.filter(r => r instanceof Error).length
      
      console.log(`${successCount} succeeded, ${failureCount} failed`)
      return { summary: { successCount, failureCount } }
    }
  },
})
```

See [Parent-Child Flows](/docs/parent-child-flows) for details.

### Shape

```ts
type ReservedJob<T = any> = {
  id: string;
  groupId: string;
  data: T;
  attempts: number;
  maxAttempts: number;
  seq: number;
  timestamp: number;
  orderMs: number;
  score: number;
  deadlineAt: number;
};
```

```ts
// Runtime `Job` entity (subset shown)
class Job<T> {
  id: string
  data: T
  groupId: string
  parentId?: string           // Set if this is a child job
  attemptsMade: number
  opts: { attempts: number; delay?: number }
  processedOn?: number
  finishedOn?: number
  failedReason?: string
  stacktrace?: string
  returnvalue?: any
  timestamp: number
  orderMs?: number
  status: 'active' | 'waiting' | 'completed' | 'failed' | 'delayed' | 'paused' | 'unknown'

  updateData(data: T): Promise<void>
  update(data: T): Promise<void>
  promote(): Promise<void>
  remove(): Promise<void>
  retry(): Promise<void>
  getState(): Promise<'active' | 'waiting' | 'completed' | 'failed' | 'delayed' | 'paused' | 'unknown'>
  getChildrenValues(): Promise<Array<T | Error | null>>  // Parent jobs only
}
```
